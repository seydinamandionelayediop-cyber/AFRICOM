# AFRICOM — Site V1

Site vitrine mobile-first basé sur la présentation AFRICOM fournie.

Services : impression digitale & offset, grand format, branding & signalétique, packaging & objets, services digitaux et solution 360°.

## Déploiement GitHub + Vercel
1. Décompresser le ZIP.
2. Créer un repository GitHub.
3. Placer `index.html`, `styles.css` et `public/` à la racine.
4. Importer le repository dans Vercel.
5. Framework : Other.
6. Build command : aucune.
7. Output directory : `.`.
8. Deploy.

Les coordonnées restent génériques car la présentation fournie ne renseigne pas de téléphone, email ou adresse.
